# مِرصد — تطبيق ويب لقراءات ماسح التربة

واجهة عربية RTL لاستقبال قيم رقمية متتابعة، رسمها مباشرةً، حفظ جلسات المسح محليًا، وتصديرها إلى CSV. هذه نسخة أولية لتحليل **تغيّر الإشارة** وليست أداة مؤكدة لتحديد معدن أو فراغ أو نوع تربة.

## تجربة التطبيق

- افتح `index.html` عبر استضافة HTTPS أو خادم محلي.
- اضغط **بدء محاكاة** لمعاينة الواجهة والمخطط. القيم في وضع المحاكاة تجريبية وليست صادرة عن الجهاز.
- لاختبار منفذ USB تسلسلي، استخدم Chrome أو Edge على جهاز يدعم Web Serial، وافتح الموقع في سياق آمن (HTTPS أو localhost)، ثم اختر المنفذ. الإعداد الافتراضي 9600 baud.
- يقرأ التطبيق سطرًا نصيًا واحدًا لكل قيمة رقمية، مثل `123\n`. غيّر `baudRate` في `index.html` إذا كانت إعدادات ESP32 مختلفة.

## تنبيه اتصال HC‑05

HC‑05 يستخدم Bluetooth Classic مع ملف المنفذ التسلسلي (SPP). واجهات الويب القياسية لا توفر اتصال SPP مباشرًا عبر Web Bluetooth، لذا لا يستطيع هذا الموقع وحده الاتصال مباشرةً بوحدة HC‑05. خيارات الربط:

1. استخدام USB تسلسلي بين الحاسوب/الجهاز والمتصفح (يدعم Web Serial على المتصفحات والمنصات المتوافقة).
2. بناء جسر وسيط يستقبل بيانات HC‑05 ويرسلها إلى صفحة الويب، مثل تطبيق Android محلي مع قناة WebSocket.
3. استخدام وحدة BLE متوافقة وتطوير اتصال Web Bluetooth مناسب لها.

## المعايرة وتفسير النتائج

ضع الحساس على مرجع تربة مناسب واجمع عدة قراءات، ثم اضغط **معايرة من القراءات**. المؤشر «قريب من الأساس/تغيّر ملحوظ» يعتمد فقط على نسبة اختلاف الرقم عن خط الأساس والعتبة المختارة. العتبة الافتراضية 18% إعداد مبدئي للعرض وليست قيمة علمية معايرة للحساس. لا يمكن استنتاج «فراغ» أو «معدن» من القيم الخام وحدها؛ يتطلب ذلك معرفة مخرجات الحساسات والدارة، اختبارات ميدانية مضبوطة، وبيانات مصنفة موثوقة.

## النشر على GitHub Pages

من إعدادات المستودع اختر **Pages**، ثم انشر من الفرع `main` ومجلد الجذر. بعد اكتمال النشر استخدم رابط Pages عبر HTTPS. التطبيق لا يحتاج إلى بناء أو تثبيت حزم.

## الخصوصية

تُحفظ المعايرة والجلسات في `localStorage` ضمن متصفح المستخدم، وتبقى على الجهاز نفسه. لا يحتوي التطبيق على خدمة خلفية أو رفع بيانات.
